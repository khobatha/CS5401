# Student snippets

Starter code for students to complete, experiment with, or modify.

Create one folder per session or topic, using the same name as the related `live-coding/` folder where applicable. Keep the distributed starter version here so it can be reused in future classes.

Each snippet's README should include:

- The learning objective and task.
- Required tools and setup commands.
- Which files or `TODO` sections students should edit.
- How to run the code.
- Expected behavior, sample input/output, or checks for completion.

Include any exercise-specific sample data alongside the starter code.
