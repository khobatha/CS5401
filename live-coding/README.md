# Live coding

Examples developed or demonstrated during CS5401 classes.

Create one folder per session or topic, using names such as `01-topic-name/`. For multiple examples in a session, use descriptive subfolders.

Each example's README should include:

- The concept being demonstrated.
- Required tools, language version, and dependency setup.
- Commands to run the example and any checks.
- Brief notes on the behavior students should observe.
